# Protótipo v4 — portal de arquitetura

Abra `prototipo-v4.html` no navegador. A página é um protótipo estático do painel do escritório e do portal do cliente; o projeto de exemplo "Apartamento Atlântico" pode ser acessado pelo endereço `prototipo-v4.html#p/apartamento-atlantico`.

A pasta `stock/` contém as imagens usadas pelo protótipo. As fontes e algumas imagens de demonstração também estão incorporadas ao HTML. As atribuições e licenças das imagens locais estão em `stock/LICENSES.json`.

Este repositório guarda a versão de design. O aplicativo Flask e o plano de evolução multi-tenant ficam no repositório separado `arqproj`.
