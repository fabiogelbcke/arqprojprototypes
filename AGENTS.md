# Instruções deste repositório

Estas regras se aplicam apenas ao repositório `arqprojprototypes`.

- Não execute `git fetch` nem `git pull` antes de cada alteração. Faça isso somente quando o usuário instruir explicitamente.
- Não crie commits nem faça push após cada alteração. Faça commit ou push somente quando o usuário instruir explicitamente. Deixe as mudanças locais para que o usuário escolha quais versões salvar.
- Sempre que o usuário instruir a criar um commit para o GitHub, capture um screenshot real da versão final do protótipo e inclua a imagem no mesmo commit, em `screenshots/`, com um nome descritivo e único. Capture a tela depois das mudanças da versão; não reutilize uma imagem de versão anterior. Se não for possível capturar o screenshot, informe o impedimento e aguarde a imagem antes de criar o commit.
